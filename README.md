# fronttier.io

Web de FRONTTIER AS: «The backstage of new territories», un atlas de los proyectos de Virginia E. Vegas. Una sola página en HTML, CSS y JavaScript, publicada gratis con GitHub Pages.

- `index.html`: textos (portada, Enclave, cierre).
- `app.js`: los proyectos (lista `T` al principio: nombre, tipo, año, enlace y una línea) y el dibujo de las islas.
- `styles.css`: diseño.

Para añadir o cambiar un proyecto: edita la lista `T` en `app.js`. Si `url` es `null`, aparece como «Sealed».
